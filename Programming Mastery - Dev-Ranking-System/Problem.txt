Lógica de Funciones y Validación de Datos

Objetivo: Desarrollar un sistema de gestión de reputación que utilice listas, bucles para múltiples calificaciones, validación de rangos y funciones modulares.

Requerimientos del Código:

Función calcular_promedio(num_proyectos: int) -> float:

Debe crear una lista para almacenar las calificaciones.

Debe pedir al usuario una nota (1.0 a 5.0) por cada proyecto usando un bucle.

Validación: Si una nota es menor a 1.0 o mayor a 5.0, debe pedirla de nuevo hasta que sea válida (no permitir negativos).

Retorna el promedio final de la lista de calificaciones.

Función calcular_reputacion(num_proyectos: int, promedio: float) -> float:

Recibe el número de proyectos y el promedio obtenido.

Retorna un puntaje basado en: num_proyectos * promedio.

Validación: Si el número de proyectos es negativo, retorna 0.0.

Función asignar_rango(puntaje: float) -> str:

De 0 a 10.0: "Novato del Código"

De 10.1 a 30.0: "Desarrollador Teso"

Más de 30.0: "Arquitecto Senior"

Función imprimir_perfil(nombre: str, rango: str):

Recibe el nombre del usuario y el rango obtenido.

Muestra un banner decorativo en consola con la información.
